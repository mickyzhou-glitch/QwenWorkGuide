# 贡献指南

## 选择合适的入口

| 你想做的事 | 推荐入口 |
| --- | --- |
| 修正错别字、失效链接或事实表述 | 内容勘误 Issue 或小型 PR |
| 更新产品能力、权益或界面信息 | 内容 Issue，附官方来源与核验日期 |
| 分享一个真实工作方法 | 在 `docs/cases/submissions/` 提交案例 PR |
| 报告密钥或隐私泄露风险 | 按 [安全政策](https://github.com/mickyzhou-glitch/QwenWorkGuide/blob/main/SECURITY.md) 私下报告 |

## 提交前自检

1. 删除个人信息、客户信息、内部资料、密钥、令牌和未经授权的截图。
2. 对产品事实给出优先级最高的官方来源和核验日期。
3. 对案例说明输入、产物、验收标准、安全边界与可公开证据。
4. 在本地运行 `npm run check`。
5. 确认你有权按文档 [CC BY 4.0](https://github.com/mickyzhou-glitch/QwenWorkGuide/blob/main/LICENSE-DOCS.md) 或代码 [MIT](https://github.com/mickyzhou-glitch/QwenWorkGuide/blob/main/LICENSE) 许可提交材料。

详细的本地命令、分支与 Pull Request 规则见仓库根目录的 [CONTRIBUTING.md](https://github.com/mickyzhou-glitch/QwenWorkGuide/blob/main/CONTRIBUTING.md)。
