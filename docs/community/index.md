# 社区共创

QwenWorkGuide 是非官方、公开维护的实践知识库。我们欢迎勘误、来源更新、可复现案例与对既有章节的改进。

## 从哪里开始

- 阅读[贡献指南](./contributing)，了解提交、核验与审阅流程。
- 阅读[内容政策](./content-policy)，确认资料、隐私、时效与 AI 辅助内容的边界。
- 使用[案例模板](https://github.com/mickyzhou-glitch/QwenWorkGuide/blob/main/.github/CASE_TEMPLATE.md)，提交脱敏且可公开复现的案例。

如果你只发现了一个错别字或失效链接，也欢迎直接提出 Issue；小修正同样能提升整本指南的可靠性。
