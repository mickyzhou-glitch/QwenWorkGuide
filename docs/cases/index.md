## 公开状态

- [蓝皮书公开案例图谱](/bluebook/part-3/09-public-case-atlas)：查看发布门、统计摘要、完整公开成员清单与证据边界。
- [案例来源映射](/bluebook/appendices/case-source-map)：在“待核验线索”中审阅候选条目的原始字段和核验状态。
- [案例核验与复用工作流](./submissions/qwenwork-public-case-atlas)：把候选线索转成可复核、可验收的内部试点记录。

示例网页、看板或报告只用于理解产物形态，不能证明案例归属、实施成本、生产稳定性或业务效果。

## 什么是合格案例

合格案例必须有案例级外部记录 ID 和稳定来源定位，并说明问题、适用角色、输入资料、执行步骤、最终产物、验收标准、权限边界、核验日期和局限。量化结果还需要完整统计口径、样本与比较基础，不能从示例产物或集合页反推。
