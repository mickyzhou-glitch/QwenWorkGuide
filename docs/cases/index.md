# 社区案例库

案例库收录从真实工作任务中提炼出的、可公开复现的实践。首版不展示虚构案例或统计数字；案例会在完成脱敏、来源核验和可复现检查后逐步加入。

## 什么是合格案例

合格案例不仅描述“用了什么”，还应交代：要解决的问题、谁适用、输入资料、使用能力、执行步骤、最终产物、验收标准和权限安全边界。这样其他读者才能判断是否适合自己的工作环境。
