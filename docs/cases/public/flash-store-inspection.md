# 官方演示：门店状态与差评巡检

**官方场景演示 · 连锁经营**

### 原文说了什么

官方教程展示门店异常状态检查及差评整理、回复文案辅助。

来源：[闪购场景实战](https://learn.qwenwork.cn/docs/scenarios/flash-shopping.html)（千问办公 · 职场 AI 三千问）。发布日期：页面未标注；查阅日期：2026-10-25。原文定位：门店营业状态巡检、差评巡检相关示例。

### 证据边界

这是教学场景，没有具名客户和效果对照；连接器与账号权限需要实测。

### 可以怎样试做

以下是本站编写的复现建议，不是对原客户内部流程的转述，也不表示本站已经实测该组织环境。

- **适合谁：** 门店运营 / 客服主管
- **准备输入：** 获授权门店列表、营业状态、评价与回复状态
- **预期交付：** 异常门店清单与待审回复稿。

用一个门店读取一次；排除正常休息；客服检查回复措辞后单独确认发送。

### 怎么验收

核对采集时刻、门店范围与已回复标志；禁止重复回复或未经授权承诺赔付。
