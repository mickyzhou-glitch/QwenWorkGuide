# 官方演示：餐饮扩张资料整理

**官方场景演示 · 专业服务**

### 原文说了什么

官方咨询页用餐饮扩张材料展示信息提取和文档交付的形式。

来源：[咨询场景实战](https://learn.qwenwork.cn/docs/scenarios/consulting.html)（千问办公 · 职场 AI 三千问）。发布日期：页面未标注；查阅日期：2026-10-25。原文定位：客户资料提取、餐饮扩张 DOCX 示例。

### 证据边界

属于演示材料；不代表某餐饮客户已采纳建议或获得经营成果。

### 可以怎样试做

以下是本站编写的复现建议，不是对原客户内部流程的转述，也不表示本站已经实测该组织环境。

- **适合谁：** 咨询顾问 / 项目分析师
- **准备输入：** 可授权使用的访谈、门店信息、扩张目标与数据日期
- **预期交付：** 客户事实表、问题清单与调研提纲。

先把访谈事实和顾问假设分开；逐条补材料出处；再形成待客户确认的文档。

### 怎么验收

核对门店数量、地区、期间；未知投资额保持空缺；避免自行补造客户背景。
