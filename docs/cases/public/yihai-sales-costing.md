# 益海嘉里金龙鱼：销售方案与新品成本

**企业实践报道 · 经营分析**

### 原文说了什么

报道列举面向餐饮客户的销售方案，以及结合配方与成本信息的新品定价辅助。

来源：[千问办公推出软硬“全家桶”！对话副总裁束骏亮：AI办公赛点还没来](https://www.zhidx.com/p/597492.html)（智东西 · 李水青）。发布日期：2026-09-25；查阅日期：2026-10-25。原文定位：效率与业务落地部分，金龙鱼段落。

### 证据边界

来源未公布核算底表和评估方法；本页不将报道中的时间缩短直接计为可复现收益。

### 可以怎样试做

以下是本站编写的复现建议，不是对原客户内部流程的转述，也不表示本站已经实测该组织环境。

- **适合谁：** 餐饮渠道销售 / 成本会计
- **准备输入：** 客户菜单需求、配方、库存成本、运费与口径说明
- **预期交付：** 菜单建议草案、成本拆分表与定价假设清单。

拆成销售建议与成本核算两项任务；先固定成本期间，再由财务核对各项输入。

### 怎么验收

复算一个配方；缺成本时标记未知；区分建议售价、含税价与实际成交价。
