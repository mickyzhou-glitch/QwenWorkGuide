# 官方演示：缺货与退款商品排查

**官方场景演示 · 连锁经营**

### 原文说了什么

官方教程展示用零售经营助手定位缺货门店与退款集中商品。

来源：[零售场景实战](https://learn.qwenwork.cn/docs/scenarios/retail.html)（千问办公 · 职场 AI 三千问）。发布日期：页面未标注；查阅日期：2026-10-25。原文定位：“库存缺货退款重点订单分析”“退款商品问题巡检”。

### 证据边界

官方说明要求商家及浏览器连接器等准备条件；不是任意账号即开即用的客户成果。

### 可以怎样试做

以下是本站编写的复现建议，不是对原客户内部流程的转述，也不表示本站已经实测该组织环境。

- **适合谁：** 零售运营 / 商品负责人
- **准备输入：** 授权订单与退款明细、门店及商品映射、缺货原因规则
- **预期交付：** 缺货门店排序、商品退款原因分布和补货建议草稿。

先读取一天数据；区分缺货、质量和其他退款；复核商品映射后交由门店处理。

### 怎么验收

排除补差单与重复记录；说明分母与部分退款口径；仅凭退款不能断言商品质量问题。
