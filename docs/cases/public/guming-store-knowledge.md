# 古茗：门店经营知识空间

**企业实践报道 · 连锁经营**

### 原文说了什么

报道以古茗为例，介绍将文档、答疑与培训信息组织成门店知识空间。

来源：[千问办公推出软硬“全家桶”！对话副总裁束骏亮：AI办公赛点还没来](https://www.zhidx.com/p/597492.html)（智东西 · 李水青）。发布日期：2026-09-25；查阅日期：2026-10-25。原文定位：企业上下文部分，古茗段落。

### 证据边界

这是企业方案报道；未公开完整部署范围、知识命中率与门店效果数据。

### 可以怎样试做

以下是本站编写的复现建议，不是对原客户内部流程的转述，也不表示本站已经实测该组织环境。

- **适合谁：** 培训负责人 / 门店运营
- **准备输入：** 已发布操作标准、答疑记录、培训安排与版本生效日
- **预期交付：** 带出处和适用版本的门店问答与培训待办草稿。

先选一个新品主题；分开有效标准和旧版资料；用门店常见问法检验引用和权限。

### 怎么验收

同题跨门店测试；过期配方不得成为当前答案；无权读取的资料不能被引用。
