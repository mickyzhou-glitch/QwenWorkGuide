# 案例投稿目录

此目录用于存放可公开复现的社区案例。每份投稿请从[案例模板](https://github.com/mickyzhou-glitch/QwenWorkGuide/blob/main/.github/CASE_TEMPLATE.md)复制，使用简短的英文或拼音文件名，例如 `meeting-summary-workflow.md`。

案例必须说明场景、输入、使用能力、任务描述、执行步骤、最终产物、验收标准、安全边界、可复现证据以及贡献者与核验日期。请只保留能够公开验证的材料：不得提交个人信息、客户机密、密钥、访问令牌、内部文件或未经授权的截图。

提交前运行 `npm run check`；维护者会核验来源、脱敏情况、复现边界和许可。
