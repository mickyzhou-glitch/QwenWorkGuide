# 快速开始：完成第一个可验收任务

目标不是一次做完复杂自动化，而是在一小时内完成一个可编辑、可验证、可回退的任务。

## 1. 选择任务

选择每周发生、输入容易准备、结果容易核对且失败可逆的任务，例如把会议材料变成纪要草稿，或把销售表变成分析底稿。

## 2. 明确边界

写清允许使用的资料、保存位置、原文件只读、是否允许写入系统，以及对外发送或发布必须人工确认。

## 3. 发送五段式指令

使用“目标、输入、约束、交付、验收”结构。先要求 AI 复述理解和处理计划；发现不清楚的字段时先提问。

## 4. 分三次检查

开始前确认范围；处理中审阅目录、字段映射或计划；结束后勾稽数字、抽查样本、打开产物确认可编辑。

## 5. 记录并复用

保存最终指令、输入要求、验收标准、失败模式和人工确认点。相同任务稳定完成两次后，再考虑沉淀为 Skill 或定时任务。

::: warning 安全边界
不要将包含个人信息、客户机密、密钥或未授权资料的内容提交到公开仓库；高风险写入、发送、删除与发布必须保留人工确认。
:::
