# 快速开始：完成第一个可验收任务

这份快速开始只做一件事：使用 [第 2 章唯一任务卡](/bluebook/part-1/02-task-delivery-protocol)，完成一个低风险、可验收的草稿任务。以下以“把已授权的会议材料整理为内部纪要草稿”为例，不在本页另建任务卡字段。

## 1. 选任务

选择输入已经取得授权、输出可以人工核对、失败后容易回到原状态的任务。先把本轮范围限定为生成内部可编辑草稿，不包含发送、系统写入或发布。

若输入来源、使用权限或最终检查人无法确认，先换一个边界更清楚的任务。

## 2. 填写任务卡

打开 [第 2 章任务交付协议](/bluebook/part-1/02-task-delivery-protocol)，按该章唯一规范逐项填写本轮任务卡，并由最终检查人确认。不要把口头要求或一段提示词当成任务卡。

需要组织调用语句时，可以使用 [提示词附录的任务交付与审核模板](/bluebook/appendices/prompt-templates#任务交付与审核模板)；任务卡字段及含义仍只由第 2 章定义。

## 3. 确认输入与权限

列出本轮实际使用的会议材料、转写、参会名单及其版本，确认每项资料的来源、日期、访问权限和允许用途。缺少资料、版本冲突或权限不明时，停止生成并请资料责任人处理。

若任务后来需要发送、写入、删除或发布，先按 [第 11 章安全治理](/bluebook/part-4/11-security-governance) 核对控制规则，展示实际对象和影响，取得所需确认并准备可验证的回退方式；本页不重新定义控制等级。

## 4. 生成草稿

把已确认的任务卡和输入交给 AI，先要求它复述任务边界，列出缺失、冲突和无法确认的内容。边界一致后，只生成内部可编辑纪要草稿，不自行补造人名、金额、日期、决定或责任归属。

保留原始输入和生成版本。需要人工确认的内容明确标出，不把未确认内容写成事实，也不执行任务卡以外的动作。

## 5. 验收与记录

由任务卡指定的检查人逐项验收草稿。验收未通过就记录退回原因并修订；无法满足任务卡要求时，结束本轮并保留问题，不用“基本可用”替代通过结论。

保存本轮任务卡、输入版本、生成版本、人工修改、异常、验收结果和最终确认记录，让下一次运行能够解释差异。

同一任务只有达到 [第 10 章“个人模板候选”阶段门](/bluebook/part-4/10-pilot-roadmap) 后，才考虑复用为个人模板；阶段门的样本、硬门和批准要求均以该章为准，不在本页复述。
