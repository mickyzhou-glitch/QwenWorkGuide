# 常见问题与排障

先记录你在哪个端、用哪个账号、想完成什么，以及第一个失败发生在哪里。不要反复运行可能已经部分成功的写入任务。

## 找到与你相似的问题

| 现象 | 先检查 | 下一步 |
| --- | --- | --- |
| 找不到新功能 | 客户端版本、所在入口、账号类型和组织策略 | 对照[更新记录](/updates/)，保留当前界面与版本信息 |
| AI 说没有文件 | 文件是否上传、工作目录是否正确、文件是否被移动 | 先让它列出能读到的文件名，再重新指定输入 |
| 连上了但读不到数据 | 目标账号、资源范围、具体工具是否支持该动作 | 用一条只读查询验证；不要盲目扩大授权 |
| 浏览器无法连接 | 扩展是否启用、浏览器是否兼容、当前连接状态 | 按[官方连接器说明](https://docs.qwenwork.cn/features/connectors)检查 |
| 定时任务没有执行 | 本地还是云端、设备状态、时区、下次运行时间 | 看运行记录；桌面任务休眠漏跑后手动验证补执行 |
| 回复完成但没有文件 | 是否确实生成产物、保存位置、下载是否成功 | 要求给出文件名称和位置，打开实际文件确认 |
| 表格数字不对 | 单位、日期范围、重复行、空值和计算公式 | 回到原始数据抽样复算，见[数据分析](/tasks/data-analysis) |
| PPT 排版错乱 | 字体、图像尺寸、对象位置、目标演示软件 | 指出具体页和对象，重新打开实际文件检查 |
| 网页预览正常但线上异常 | 发布状态、数据服务、账号权限、请求或流量额度 | 以正式链接验证，检查[网页说明](https://docs.qwenwork.cn/web/pages) |

## 追问和自动审批要分开理解

客户端 1.3.1 的“追问超时选择推荐项”是可选设置，不代表你需要默认接受所有建议；安全中心中的自动审批机制也不等于业务负责人已经授权某笔发送、删除或投放。处理不清楚的问题时，先保留原始输入和具体失败信息。[官方客户端日志](https://docs.qwenwork.cn/release-notes/desktop)

## 给出足够具体的反馈

```text
环境：网页端或桌面端，系统与客户端版本
账号范围：个人或企业，是否切换过组织（不要提供凭据）
目标：本来想完成什么
步骤：从哪个入口、用了什么匿名样本、操作到哪里
现象：实际出现什么，与预期差在哪里
材料：脱敏错误信息、任务时间、必要截图
已尝试：做过哪些检查，是否发生了部分写入
```

官方反馈工具如果支持诊断导出，分享前仍应检查其中是否包含不适合公开的材料。本站可以受理内容勘误；产品账号、额度和服务故障请通过官方渠道处理。
