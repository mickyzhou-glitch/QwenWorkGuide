# 技能、连接器与专家套件

不是资源装得越多，任务就越容易成功。先知道缺的是方法、数据，还是一整套岗位工具。

## 三种扩展如何选

| 扩展 | 解决的问题 | 使用前检查 |
| --- | --- | --- |
| 技能（Skill） | 一类任务怎样做、按什么格式交付 | 来源、输入要求、执行步骤、是否含脚本或外部服务 |
| 连接器（Connector） | 访问外部平台、账号、数据与工具 | 目标账号、授权范围、支持的具体动作 |
| 专家套件（Expert Kit） | 为某类岗位组合多项能力 | 包含什么资源，哪些仍需单独配置或授权 |

这一区分来自[官方扩展说明](https://docs.qwenwork.cn/features/extensions)。专家套件不是效果保证；连接器连接成功也不等于所有操作都被授权。

## 用一次小任务验证

1. 在“扩展”中按任务查找资源，先阅读说明再安装。
2. 需要外部账号时完成对应授权，并确认登录的是正确的个人或企业账号。
3. 在新任务中明确说明使用哪个资源、读哪些材料、生成什么结果。
4. 先验证一项只读操作，例如读取指定文档标题；不要一上来批量修改。
5. 核对结果与原系统一致，再扩大到实际任务。

可以这样提需求：

```text
请使用已安装的相关技能整理这份周报材料。
开始前说明你实际能读取的文件、将使用的资源及缺少的授权。
输出一页周报，保留进展、风险、下周计划三个部分。
若连接器不能读取指定材料，请说明原因，不要猜测内容。
```

## 把一次好做法留下来

对于已经跑通的方法，整理触发条件、输入要求、操作步骤、输出模板和检查方法，再做成技能。用正常样本、缺少字段的样本、格式变化的样本各测试一次，确认它不只是复述成功时的对话。

[官方技能说明](https://docs.qwenwork.cn/features/skills)介绍了获取、调用与管理方式。分享前检查是否包含客户文件、个人路径、账号凭据或组织专属内容；公开分享与组织内共享的范围不同，组织资源还受管理员规则约束。

## IM 频道与业务连接器也不一样

IM 频道解决“从哪里发指令、结果回哪里”；业务连接器解决“能读取或修改哪些业务数据”。把机器人接进聊天工具，不代表自动获得该组织全部文档和消息权限。

官方 [IM 频道说明](https://docs.qwenwork.cn/desktop/im-channels)指出，IM 发起的任务结果回到原聊天窗口。群聊任务尤其要先判断结果是否适合被全群看到。
