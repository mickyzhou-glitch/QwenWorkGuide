# 千问办公能力地图

先回答两个问题：**资料在哪里，最后要交付什么？** 选入口比一开始研究所有功能更有用。

## 先选适合的入口

| 入口 | 优先用于 | 开始前看什么 |
| --- | --- | --- |
| 网页端 | 上传资料、在线研究、生成文档与网页 | 上传范围、云端文件位置、当前套餐 |
| 桌面端 | 本地文件夹、浏览器和电脑应用相关任务 | 系统权限、工作目录、需要启用的连接器 |
| 手机 App | 移动途中发起与跟进任务 | 应用商店与账号可用性、附件和结果是否完整 |
| IM 频道 | 从协作工具发起任务、接收结果 | 频道是否已连接、对应组织、结果回传位置 |

网页端与桌面端的基本流程可查[官方网页指南](https://docs.qwenwork.cn/getting-started/basic-workflow)和[桌面指南](https://docs.qwenwork.cn/getting-started/desktop-workflow)。手机 App 上线信息见[9 月 30 日官方动态](https://learn.qwenwork.cn/whatsnew/)，不能据此假定手机可直接控制你未连接的电脑。

## 从产物选做法

| 你需要 | 建议先做 | 本站实操 |
| --- | --- | --- |
| 文档与纪要 | 明确读者、结构与原文依据 | [会议纪要](/tasks/meeting-notes) |
| 表格与图表 | 对齐统计口径，保留原始表 | [数据分析](/tasks/data-analysis) |
| PPT 与汇报 | 先定结论和大纲，再做排版 | [汇报制作](/tasks/presentation) |
| 有来源的报告 | 限定对象、日期、比较维度 | [竞品研究](/tasks/research) |
| 网页或小型应用 | 区分纯展示与共享保存数据 | [团队工作台](/tasks/team-workspace) |
| 经营复盘 | 先验证指标，再接后台数据 | [电商复盘](/tasks/commerce) |

官网介绍了办公产物、多模态处理、网页交付和数据接入等方向。具体格式、工具、额度和操作范围仍取决于当前环境；“能生成”之后，还要打开产物检查是否可用。[官网能力概览](https://qwenwork.cn/)

## 四组容易混淆的概念

**技能与连接器：** 技能侧重如何处理任务；连接器侧重能访问哪个系统。安装一个写作技能，不会自动获得企业文档访问权。[看扩展指南](/guides/extensions)

**任务与项目：** 一次任务解决一个目标；项目用于组织相关任务和材料。长期项目应使用稳定目录，避免把每次输入都散落在临时下载中。

**个人记忆与团队规范：** 桌面端“意识”可维护协作风格、工作手册及记忆。先写稳定的偏好和工作规则；过时的事实要纠正，不要把记忆当作不需要复核的资料库。[官方意识说明](https://docs.qwenwork.cn/desktop/memory)

**本地定时与云端定时：** 网页端任务在云端运行；桌面端定时依赖本机运行条件。两者不能混为“关机也能跑”。[看自动化指南](/guides/automation)

## 功能没有出现时

按“入口与版本 → 账号与组织 → 管理员策略 → 安装与授权 → 单次测试”检查。尤其电商经营模式、企业管理能力和第三方资源，不能只因在更新日志中出现，就假定你的账号已经开放。
