# 蓝皮书 V2.1 与公开案例扩充

用户要求补齐蓝皮书正文和 PDF，扩展公开案例，并延续直接发布及同步 GitHub 的授权。

## 本次范围

- 原位更新全部 13 章、执行摘要与结语；补充移动端、企业上下文、技能分享、安全审批、电商经营、云端与本机定时差异。
- 新增来源登记和 13 个详情页：7 条企业报道、1 条第三方实测、5 条官方场景演示。
- 在线目录、案例详情与 PDF 案例札记使用同一份数据生成；检查来源存在、重复位置、日期与生成内容一致性。
- 新增 V2.1 PDF 清单；保留 V2.0 文件与旧证据日期，不将历史候选升级为客户成果。
- 发布前检查测试、内容、两种站点路径、PDF 渲染和线上资源。

## 证据口径

来源为新华网客户端 / 消费日报、智东西、财经杂志的新浪转载、投资界的新浪实测稿和千问办公官方场景页。新闻转载不重复计数；同一客户的多个流程合为一个条目。发布日期未知保持 null。报道事实、局限与本站试做建议分别存储；不复制整篇原文、不发布内部资料，不将经营者自述数字当作独立评估。

原有 32 条候选仍沿用原案例级证据门。新增条目统计的是可定位公开材料，并非通过独立收益审计的客户数。

## 阅读与维护

新增内容进入各章主体开头，并修订过时的三入口表述；方法和原证据锚点保持可访问。首页、阅读指南、案例目录、蓝皮书与更新页统一指向 V2.1。历史证据与补充证据按各自日期读取。
