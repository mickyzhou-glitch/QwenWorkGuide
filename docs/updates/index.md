# 产品更新与阅读提示

## 三个容易踩坑的边界

### 云端定时与本地定时不同

[网页端说明](https://docs.qwenwork.cn/web/scheduled-tasks)表示关闭浏览器后仍可在云端运行；[桌面端说明](https://docs.qwenwork.cn/desktop/scheduled-tasks)要求本机保持唤醒，漏跑不自动补执行。按实际运行环境配置，不把一种说明套到所有入口。

### 有历史版本，不等于已有一键回滚

[我的网页](https://docs.qwenwork.cn/web/pages)的具体操作中，“切换版本”仍标为即将上线。保留源文件与数据导出，实际确认恢复能力后再制定上线方案。

### 权益不要照搬旧材料

产品入口、套餐、积分、第三方服务权限和试用政策可能分别更新。本站不将历史报价或服务商材料写成当前公开承诺；查阅[官方权益说明](https://docs.qwenwork.cn/benefits)并以当前账号及合同为准。

## 本站这次改了什么

2026-10-25 阅读体验重构：

- 首页改为按任务进入，增加搜索与分类，六个任务分别有独立实操页。
- 快速开始改为可以直接粘贴练习的小样本，不要求先通读组织方法。
- 新增能力地图、扩展、自动化、团队试点与排障指南。
- 保留全部旧章节网址；蓝皮书与 PDF 明确标记 8 月历史快照。
- 统一导航与两种托管路径，增加发布前的站内链接和锚点检查。
