# 把会议变成行动清单

**带走什么：** 一页纪要、一张行动清单，以及一组确实需要追问的问题。

## 准备材料

提供已获使用许可的会议记录或转写、会议日期、参会名单。已有录音转写时优先直接用文字；识别不清的人名、数字和时间保留原文片段。录音设备不是完成这项练习的前提。

## 操作步骤

1. 新建任务，上传或粘贴记录，注明会议日期与时区。
2. 先让 AI 分开整理“已作决定”“讨论意见”“尚未决定”，检查是否混淆。
3. 再提取行动清单；只给原文明确指定的人分配任务。
4. 逐条回看来源；把缺负责人、缺时间的项目集中列出，请参会人补充。
5. 生成可编辑纪要和行动表；在正式发送或创建待办前核对对象与内容。

## 可复制的指令

```text
根据我提供的会议记录，生成内部纪要与行动清单。
会议日期和参会名单以附件为准。
输出三部分：
1. 会议结论：区分已确认决定、建议和未决事项。
2. 行动表：事项、负责人、截止日期、依赖条件、原文依据。
3. 需要补问的问题：只列影响后续推进的缺失信息。
原文没说的内容写“待确认”，不要为了完整而补造。
先展示草稿，核对后再生成可编辑的文档与表格。
本轮不发送消息、不创建待办。
```

## 这样检查才算做完

| 检查点 | 通过的样子 |
| --- | --- |
| 决议 | “考虑”“暂定”没有被写成最终决定 |
| 责任 | 每个负责人都能在记录中找到依据 |
| 日期 | 相对时间按会议日期解释，无法确定的时间留空或标注 |
| 遗漏 | 争议、前置条件和未决事项没有被摘要吞掉 |
| 文件 | 文档和表格能打开、能编辑，格式没有错行 |

若识别结果有误，先改转写再改纪要；不要用更流畅的表达掩盖错误的人名或数字。

## 进阶：衔接协作工具

需要读取组织资料、创建日程或待办时，先确认对应连接器可用、账号已授权。使用 IM 频道发起的任务可能把结果回传到原聊天窗口，私密会议内容应先在合适的私有任务中整理。详见[扩展与连接器](/guides/extensions)。
