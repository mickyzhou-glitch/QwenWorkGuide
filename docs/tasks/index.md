# 按任务找方法

选一个今天要交付的成果。下面的实操是社区建议，每页都包含输入、步骤、可复制指令和检查方法；不代表固定完成时长或效果承诺。

## 第一次用

先用[快速开始](/guides/quick-start)里的虚构会议材料练习。卡在账号、文件、连接器或输出环节时，查看[常见问题与排障](/guides/troubleshooting)。

## 从实操到案例

这里的任务练习与[案例库](/cases/)用途不同：练习帮助你动手，案例用来观察场景、输入和产物。案例中尚未完成核验的效果，不作为你的收益承诺。
