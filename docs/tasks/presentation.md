# 把零散材料做成汇报

**带走什么：** 可编辑 PPT、一页讲述提纲，以及需要补证据的内容清单。

## 准备材料

给出汇报对象、希望对方作出的决定、可用时长、数据期间和品牌模板。把事实材料与个人设想分别标注；品牌模板中的图片和字体要有使用权。

## 操作步骤

1. 先生成一页“核心结论 + 证据 + 希望获得的决定”，判断汇报是否聚焦。
2. 让 AI 按讲述顺序列每页标题、要点和需要的图表；此时先不美化。
3. 修改结构，删掉重复或没有证据支撑的结论。
4. 生成 PPTX；指定标题、正文、图表均应尽量保留可编辑对象。
5. 用实际演示软件打开，逐页检查，再按听众反馈修改。

## 可复制的指令

```text
基于附件做一份给业务负责人看的月度经营汇报，预计讲 10 分钟。
请先拟 8 页大纲，每页只讲一个结论，注明结论依据和缺少的数据。
结构：本月结论、目标差距、主要变化、原因分析、下月行动、需要的支持。
未经材料支持的数字不补造，预测与事实分开。
我确认大纲后，再生成可编辑的 PPTX，并附逐页讲述要点。
使用简洁商务风格；图表标注单位、期间和数据来源。
```

## 这样检查才算做完

| 检查点 | 方法 |
| --- | --- |
| 数字 | 对照原表抽查金额、占比、排序与图例 |
| 可编辑性 | 尝试修改一段文字、一张图表与一个标题 |
| 排版 | 检查溢出、遮挡、字体替换、页边距和图片清晰度 |
| 叙事 | 只读每页标题，也能理解整份汇报的逻辑 |
| 使用 | 在要用的设备上打开文件，检查备注与演示顺序 |

“帮我做得更高级”通常不够具体。可以说：“第 4 页删除右侧装饰，将两张图合为一张对比图，保留全部数据标签。”

## 其他产物

同一份材料还可以整理成 Word 汇报或周报。要按新的读者和用途重组，不能只把幻灯片文字顺次拼接。
