# 做有来源的竞品研究

**带走什么：** 一张竞品对照表、来源清单与带判断边界的研究摘要。

## 准备材料

限定要比较的对象、产品版本、地区和截止日期。例如比较三个产品的某一项业务能力，不把母公司、全部产品线和不同地区套餐混成一张表。

## 操作步骤

1. 先列比较维度并确认：功能范围、使用门槛、集成条件、计费口径和适用人群。
2. 优先寻找官网、帮助中心、公开财报或原始公告，记录发布日期与核验日期。
3. 为每条关键结论附具体页面链接；搜索摘要只作线索。
4. 对冲突来源保留差异，不为了表格整齐而强行填值。
5. 写摘要时把事实、推断、建议分开，人工点开关键来源抽查。

## 可复制的指令

```text
比较我指定的三个产品在指定地区、截止日期前公开的能力。
先确认比较维度，优先使用官网、官方帮助中心和原始公告。
输出表格：产品、版本、能力说明、使用条件、来源链接、资料日期、核验日期。
没有可靠来源写“未找到公开依据”，不要把未找到当作不支持。
价格必须带计费周期与套餐范围，无法核对就留空。
再写一页结论，分开标注公开事实、你的推断和需要进一步验证的问题。
```

## 这样检查才算做完

- 打开关键链接，确认不是失效页、广告聚合页或与结论无关的文章。
- 检查发布日与生效日；旧版本的限制不能直接推到当前版本。
- 数字有单位与样本范围，客户宣传结果与独立评测分开。
- 结论注明覆盖范围；不能由一个演示推断所有客户都能实现。

如果来源需要登录或无法访问，记录这一限制，请用户提供有权使用的材料，或缩小结论范围。

## 进阶：把研究做成周报

先固定对象、维度和来源，再让[定时任务](/guides/automation)只追踪新增变化。没有新信息时明确写“本期未发现新增公开信息”，不要编出更新。
