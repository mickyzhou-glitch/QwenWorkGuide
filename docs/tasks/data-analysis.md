# 做一份可信的数据分析

**带走什么：** 保留原始数据的分析工作簿、清洗说明、图表和一页结论。

## 准备材料

使用已授权的 Excel 或 CSV 副本，注明统计期间、币种、金额单位、含税口径、业务主键和退货处理规则。不要直接让 AI 改写唯一原件。练习时用匿名样本即可。

## 操作步骤

1. 先让 AI 列出工作表、字段、行数、日期范围及缺失值，确认它读对了文件。
2. 对齐“收入”“订单”“净额”等定义；含税与不含税、元与万元不要混加。
3. 生成清洗后的新表，保留原始表，记录去重、排除和格式转换规则。
4. 再按月份、产品或区域分析，要求保留公式或明确计算口径。
5. 从明细抽样复算，并核对总额；通过后再生成图表和摘要。

## 可复制的指令

```text
分析我提供的销售数据副本，输出一个新的 Excel 工作簿。
先读取字段、行数、日期范围、币种与金额单位，不明确就先问我。
原始数据保持不变，另建“清洗数据”“汇总分析”“问题记录”工作表。
汇总每月销售额、订单量和客单价，并说明退货和重复记录的处理方法。
提供能追溯到明细的公式或计算说明，图表与汇总表口径一致。
把异常与缺失单独列出，不用猜测值填补。
最后输出一页结论，区分数据观察和可能原因。
```

## 这样检查才算做完

- **勾稽：** 清洗前后的金额差异能逐项解释，各组汇总之和与总计一致。
- **公式：** 抽查正常值、零值和空值，分母为零时不产生误导性百分比。
- **趋势：** 没有把一个月的部分数据与另一个整月直接比较。
- **归因：** “销售下降”是观察；“因为促销减少”需要额外证据。
- **可维护：** 工作簿能编辑，新增一行数据后知道哪些公式或图表需要刷新。

扫描版 PDF 表格应先抽查提取准确性。数据缺了整段日期时，先补输入，不急着出趋势结论。
