# 可复用资产：Skill（技能）、连接器与专家套件

## 30 秒结论

<span id="claim-skill-asset-boundary-01" data-claim-id="claim-skill-asset-boundary-01"></span>本书将 Skill 定义为封装可重复方法和工具步骤的版本化资产；它解决“这件事按什么步骤做”，不自动取得数据权限，也不替代专业验收。

- 连接器规定经授权的数据和动作边界，不承载完整业务方法。
- 专家套件组合多个已发布工作流和岗位标准，不是若干提示词的打包。
- 三类资产都必须有 Owner、版本、输入输出、测试样本、权限说明和发布门。

## 为什么重要

团队常把提示词、账号连接和岗位知识混在一个“智能助手”中。出现错误时，无法判断应该改方法、收紧授权，还是更新专业标准；共享时也容易把个人权限和未验证步骤一并扩散。

清晰的资产边界让企业分别管理内容质量、系统权限和岗位责任。它也决定复用是否可审计：谁批准了哪个版本，使用了哪些测试样本，能访问什么数据，失败后回到哪里。

## 方法或模型

| 资产 | 规范定义 | 适用条件 | 主要 Owner |
|---|---|---|---|
| Skill | 封装可重复方法、工具步骤、判断规则和交付格式 | 同类任务输入稳定，步骤可测试，失败可识别 | 工作流 Owner |
| 连接器 | 提供经授权的数据读取或动作调用边界 | 系统对象、账号、权限和读写范围明确 | 系统 Owner、数据 Owner |
| 专家套件 | 组合多个已发布工作流、岗位知识和专业标准 | 岗位任务链稳定，组成资产已通过阶段门 | 岗位负责人、专业质量 Owner |

每项资产都用同一发布合同登记：

| 字段 | 必填内容 | 发布前证据 |
|---|---|---|
| Owner | 对结果、权限或专业标准负责的具体角色 | 责任确认和升级联系人 |
| 版本 | 版本号、变更内容、兼容范围和回退版本 | 变更记录、可恢复的上一版本 |
| 输入输出 | 输入字段、可信范围、输出格式和保存位置 | 合法样本、缺失样本、产物示例 |
| 测试样本 | 正常、边界、冲突和失败样本 | 测试记录、人工修改和未通过原因 |
| 权限 | 数据对象、读写范围、凭证归属和有效期 | 授权记录、最小权限检查 |
| 发布门 | 当前阶段、通过条件、停止条件和批准人 | 阶段评审记录和发布决定 |

<span id="claim-connector-authorization-01" data-claim-id="claim-connector-authorization-01"></span>连接器的产品作用是连接外部数据或工具；实际可访问的数据和可执行动作受当前授权与可用范围约束，不能因“已连接”推定拥有完整读写权限。

<span id="claim-expert-kit-release-01" data-claim-id="claim-expert-kit-release-01"></span>本书建议：专家套件只能组合已经通过岗位阶段门的工作流，不能用套件名称替代组成资产的测试、权限和责任记录。

复用升级遵循第 10 章的阶段门，本文不复制样本数和阈值：个人模板完成 0–30 天阶段门后才成为候选资产；团队工作流完成 31–60 天阶段门后才可发布为团队 Skill；岗位专家套件只能组合通过 61–90 天阶段门的工作流。

## 案例与证据

官方帮助中心分别提供 Skill 和连接器说明。 [R8](/bluebook/appendices/sources#r8) [R4](/bluebook/appendices/sources#r4) 本章采用其公开产品语境，但“资产发布合同”和阶段门映射是社区治理方法，不代表官方产品承诺。

一个周度经营复盘 Skill 可以固定输入检查、数据勾稽、异常识别和产物格式；连接器只负责在授权范围内读取项目台账或创建待办草稿；专家套件再把经营复盘、风险升级和管理层汇报等已发布工作流组合起来。任一连接器失效时，方法资产仍应能降级到人工提供输入，而不是静默生成不完整结论。

## 企业行动

对现有共享提示词做一次资产拆分：

1. 把可重复步骤、判断规则和交付格式整理为 Skill 候选。
2. 单独列出每个数据源和动作，区分读取、草稿写入和正式执行。
3. 指定工作流 Owner、系统 Owner 和专业质量 Owner。
4. 为正常、缺失、冲突和越权输入各准备测试样本。
5. 登记当前阶段门；未通过时只限个人或受控试点使用。

停止发布的信号包括：没有具体 Owner；输入输出依赖口头约定；测试只覆盖成功样本；连接器申请超出任务所需权限；无法回到上一稳定版本；专家套件包含尚未独立验收的工作流。

## 边界与下一步

一个好的提示词可以是 Skill 的素材，但不是完整的团队资产。连接器可用也不意味着业务动作已获批准；专家套件中的专业判断仍由具备相应职责的人承担。

本章定义资产边界和发布关系，不定义自动化运行中的接管与恢复。资产进入定时或无人值守运行前，还需要独立的运行控制。
