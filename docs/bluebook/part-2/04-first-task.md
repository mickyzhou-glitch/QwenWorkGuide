# 完成第一项任务

## 选对第一项任务

选择每周至少发生一次、输入容易准备、结果易判断且失败可逆的任务，例如资料整理、Excel 分析、Word 转 PPT 或会议纪要草稿。

## 五段式任务说明

1. **目标**：最终帮助谁做什么决定；
2. **输入**：允许使用的文件、消息、网页或数据源；
3. **约束**：时间范围、口径、风格与不能做什么；
4. **交付**：格式、结构、保存位置与命名；
5. **验收**：准确、完整、可用的判断标准。

## 可直接使用的第一条指令

```text
目标：把销售明细整理成经营会使用的分析报告。
输入：只使用指定文件；字段不清楚时先提问，不要猜测。
分析：按月、区域、产品和客户分层，计算收入、环比、客单价和前十客户贡献。
交付：生成可编辑 Excel 和 8 页以内 PPT，保存为新文件。
验收：汇总数与原表勾稽；图表标明时间范围和单位；异常值单列说明。
边界：不得修改原文件；不得向外发送或发布。
```

## 运行中的三次检查

- 开始前：确认文件、权限和时间范围；
- 中途：先审阅目录、字段映射或分析计划；
- 结束后：核对总数、抽查样本并确认文件可编辑。

| 失败现象 | 修正方法 |
|---|---|
| 口径不对 | 先输出字段理解与口径假设 |
| PPT 没有决策信息 | 明确受众、决策和关键结论 |
| 公式错误 | 加总额校验与样本抽查 |
| 覆盖原文件 | 明确只读原件与新文件命名 |
| 无法复用 | 将稳定步骤固化为 Skill |
