# 岗位路线：从个人提效到专业套件

## HR

汇总候选人进展与入职准备，提醒缺失反馈；发送前人工确认。指标：报告准备时长、反馈完整率、候选人等待时长、误匹配率。

## 销售与商务

将公开信息、CRM/表格、历史沟通和产品资料组合为客户画像、拜访提纲与方案；会后生成邮件草稿和待办。报价、承诺与对外发送必须人工确认。

## 产品与项目

从需求文档、群聊、周会、缺陷和路线图提取变化，形成状态、风险与决策请求。指标：状态汇总时间、遗漏风险、决策等待时长与变更可追溯率。

## 财务与法务

财务适合数据核对、异常标记和报表草稿，不应无复核记账、付款或改主数据。法务可提取合同条款和到期提醒，高风险条款交由法务复核。

## 内容与市场

把趋势研究、选题池、内容生产、素材生成和效果数据串成闭环。发布默认人工确认，复盘结果反哺选题 Skill。

## 四级成熟度

| 级别 | 使用方式 | 典型特征 |
|---|---|---|
| M1 助手 | 临时问答与草稿 | 个人使用、无统一模板 |
| M2 工具 | 稳定产物与局部操作 | 有验收标准、节省明确时间 |
| M3 流程 | Skill + Connector + 定时任务 | 可复用、可监控、有失败回退 |
| M4 系统 | 专家套件 + 组织数据 + 治理 | 跨岗位协同、持续优化、可度量 |
