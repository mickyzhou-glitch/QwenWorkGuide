# 三端一体：Web、桌面与钉钉

千问办公公开提供 Web、桌面和钉钉内入口；应把它们看作三种工作环境，而不是同一聊天框的不同尺寸。[来源](../appendices/sources#r2) [来源](../appendices/sources#r3)

## Web 端：云端任务与在线交付

适合上传资料、研究、生成文档、管理云端产物、运行云端定时任务，以及制作网页。典型任务包括公开资料研究、数据可视化和活动页制作。

## 桌面端：本地上下文与深度执行

官方说明桌面端可处理本地文档、表格、图片和视频，并保存到原路径或指定文件夹。[来源](../appendices/sources#r3) 它适合本地文件、系统应用、浏览器登录态与电脑操控等上下文。

## 钉钉端：组织上下文与协作闭环

钉钉端可将企业消息、群聊、日程、待办、日志、审批、考勤、文档和知识库等组织上下文接入任务。官网披露支持 25 项企业 IM 能力；实际范围取决于管理员开通和授权。[来源](../appendices/sources#r2)

## 三端选择原则

| 主要依赖 | 优先入口 | 原因 |
|---|---|---|
| 云端资料、在线生成、网页发布 | Web | 跨设备、云端持续运行 |
| 本地文件、系统应用、浏览器登录态 | 桌面端 | 上下文完整，可直接操控 |
| 组织消息、日程、待办、流程协作 | 钉钉端 | 权限与协作链路在场 |
| 多环境同时参与 | 桌面端发起，钉钉跟进 | 执行、确认与接管分工 |

## 钉钉协同能力地图

知识库列出的深度集成能力覆盖文档、AI 表格、知识库、日程会议、AI 听记、消息、群聊、邮件、云盘、待办、通讯录、考勤、DING 与审批等对象。[来源](../appendices/sources#r10) 能“访问”不等于能“自动执行”，具体范围取决于组织开通、账号权限、连接器状态与动作确认。

| 协同对象 | 典型任务 | 推荐交付 | 默认风险策略 |
|---|---|---|---|
| 文档 / 知识库 | 创建、改写、总结、归档、查询 | 文档草稿、知识条目、来源清单 | 新建可自动；覆盖与移动前确认 |
| AI 表格 | 建表、结构化整理、数据分析 | 数据表、看板、异常清单 | 先校验字段与主键，再写入 |
| 日程 / 会议 | 查空闲、约会、准备材料 | 议程、参会清单、会议安排 | 正式邀约前确认对象与时间 |
| AI 听记 | 纪要、决定、待办提取 | 纪要、责任矩阵、待确认项 | 人名、日期、金额必须复核 |
| 消息 / 群聊 | 总结、提炼分歧、提醒 | 摘要、风险、回复草稿 | 读取可自动；发送前确认 |
| 邮件 | 摘要、起草、跟进 | 邮件草稿、附件清单 | 收件人、承诺与附件强制复核 |
| 云盘 | 查找、分类、提取信息 | 文件索引、分类建议、重复项 | 不删除；移动前提供清单和恢复路径 |
| 待办 / DING | 创建任务、催办关键事项 | 待办草稿、催办计划 | 负责人、截止日与提醒范围确认 |
| 通讯录 / 考勤 | 组织查询、异常汇总 | 组织分析、考勤异常清单 | 最小范围读取，限制敏感字段传播 |
| 审批 | 准备材料、发起流程 | 审批草稿、附件与依据清单 | 发起、金额与审批链强制确认 |
