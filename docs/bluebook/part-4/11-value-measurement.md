# 如何衡量价值

DAU、对话数和 Token 消耗只能说明使用，不足以证明价值。建议建立四层指标：

- **使用层**：活跃人数、任务数、重复使用率、Skill 使用率、连接器启用率；
- **效率层**：单任务处理时长、等待时长、人工步骤数、跨工具切换次数；
- **质量层**：一次通过率、数字错误率、引用完整率、返工次数、异常发现率；
- **业务层**：交付周期、销售跟进速度、月结周期、风险响应时间、客户满意度。

## ROI 计算模板

```text
月度净收益 =
（基线耗时 − AI 后耗时）× 月任务量 × 人力小时成本
+ 因质量提升避免的损失
+ 因交付加速带来的增量价值
− 订阅与积分成本
− 实施、培训、审阅和治理成本
```

## 商业化判断

::: info 社区观点
更可持续的价值通常来自四类资产：正式产物环境、系统连接、可复用流程，以及岗位专业知识与交付标准。它们越深入工作流，组织价值与迁移成本越高。
:::

## 公开价格页带来的成本口径修订

截至研究快照日，官网个人权益页列出免费版、个人标准版与个人高级版，并以积分、并行任务、网页版云盘与可发布网页数量区分权益；新用户赠送和每日登录积分属于限时权益。[来源](../appendices/sources#r12) 业务侧不宜把会员价直接当成单任务成本，也不宜把限时赠送纳入长期 ROI。

| 采购/试点评估项 | 应记录的口径 | 常见误判 |
|---|---|---|
| 积分消耗 | 按任务类型、输入大小、重跑次数记录中位数与 P90 | 用一次直播演示或首月赠送外推全年成本 |
| 并发与排队 | 高峰时段等待时间、可并行任务数 | 只比较标价，不看交付截止日 |
| 云端资源 | 存储、网页发布、数据库等实际占用 | 将测试网页误当作正式生产托管 |
| 人工成本 | 复核、返工、连接器维护和异常处理 | 只计算生成时间，忽略治理成本 |

建议在前 30 天建立“积分—产物—人工分钟”台账；积累 20 个以上真实样本后，再决定订阅档位、共享资源和岗位推广范围。
