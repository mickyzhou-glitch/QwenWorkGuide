# 价值度量：从使用数据到可复算决策

## 什么时候需要看

如果你只是想知道一份草稿是否好用，可以先按任务验收，不必马上计算价值。只有当你要决定是否继续投入一份自动生成的周报、经营汇报或其他团队工作流，比较人工时间、质量、风险、现金投入和可释放产能时，再回到本章。先记住一句普通话：使用量不等于价值，价值要能回到任务、验收、风险记录和成本凭证。

## 30 秒结论

<span id="claim-usage-not-value-01" data-claim-id="claim-usage-not-value-01"></span>DAU、对话数、Token 和产物数只能说明使用，不能单独证明企业 AI 已产生业务价值。

<span id="claim-capacity-separate-01" data-claim-id="claim-capacity-separate-01"></span>现金 ROI 与可释放产能必须分开报告；质量和风险也单独报告，只有形成可核验的实际损失或收益时才进入现金口径。

- 先锁定任务、分母、基线和人工成本，再看试点结果。
- 节省工时不自动等于现金收益，新增产物也不自动等于增量收入。
- 扩大、优化、保持试点或停止，都要回到试点前登记的阈值和硬门。

## 为什么重要

使用量很容易取得，也最容易被误读。一次任务可能产生多轮对话和多个文件，却没有通过验收；生成时间下降，也可能把输入准备、复核和返工转移给其他人。若团队只展示活跃人数或“节省小时”，就无法判断成本是否真实下降、质量是否保持、风险是否增加。

价值度量的用途不是为 AI 找一个更大的数字，而是帮助业务负责人配置资源。可复算的价值账要让未参与试点的人沿着任务样本、时间记录、验收结果、风险事件和成本凭证复核结论，并看见不能现金化的部分。

## 方法或模型

### 先锁定场景、样本和基线

度量单位是一个边界明确、结果可验收的场景，不是“全公司使用 AI”。试点开始前登记：

- 任务起点、终点、符合资格的任务和排除规则；
- 基线期、试点期、季节性和任务难度的比较方法；
- 有效任务分母，以及失败、中止和排除任务的留痕规则；
- 人工输入准备、执行、等待、复核、返工、沟通和异常处理时间；
- 一次通过、退回、关键错误、风险事件和业务结果的定义；
- 订阅、积分、实施、培训、维护、治理和失败损失的凭证或估算依据。

所有已启动任务都保留结果。被排除的任务要保留理由，关键错误和未授权事件不得因排除而从风险记录消失。基线和试点使用同一验收标准；口径变化时应重新建立基线，不把不可比较数据拼成平均值。

### 分层记录，而不是先算一个总分

| 层次 | 最低记录 | 能回答的问题 | 不能单独证明 |
|---|---|---|---|
| 使用 | 符合条件任务数、运行数、使用者、重复使用、DAU、对话数、Token、产物数 | 是否有人使用、负载如何 | 质量、现金收益或业务结果 |
| 效率与产能 | 基线与试点总时长中位数、等待、人工步骤、同口径有效任务量 | 时间在哪里变化、可释放多少产能 | 支出已经减少 |
| 质量 | 一次通过、人工修改、返工、关键错误、专业复核结果 | 交付是否达到同一标准 | 风险已经可接受 |
| 风险 | 未授权事件、隐私与权限问题、错误对象、失败损失和接管结果 | 是否触发硬门或停止条件 | 业务价值可以抵消风险 |
| 现金 | 已实现收益、增量成本、凭证、归因和敏感性 | 已实现现金结果能否复算 | 未现金化产能的未来价值 |

### 使用唯一现金与产能口径

<span id="claim-cash-roi-formula-01" data-claim-id="claim-cash-roi-formula-01"></span>本书建议：现金 ROI 只纳入已经实现或有可核验依据的现金收益，并计入从输入准备、人工复核到治理和失败损失的全部增量成本。

```text
已实现现金收益 = 已实际减少的支出
               + 有预算依据且可证明的支出避免
               + 可归因的增量毛利

增量总成本 = 订阅与积分 + 实施 + 培训 + 输入准备 + 人工复核
           + 返工 + 维护 + 治理 + 已实现的失败损失

现金净收益 = 已实现现金收益 − 增量总成本
现金 ROI = 现金净收益 ÷ 增量总成本

可释放产能 =（基线单任务总时长中位数 − 试点单任务总时长中位数）
             × 同口径有效任务量
```

现金收益与成本必须使用同一统计期间、币种和价格口径。一次性成本和持续成本分列；若用于跨周期决策，应披露一次性成本的处理规则、覆盖周期、各期持续成本和未计入项目，并服从组织财务制度。禁止混用年收益与月成本，也不能把预测期间收益与已实现期间成本放在同一现金 ROI 中。

增量总成本小于或等于 0 时，不计算或展示现金 ROI。此时报告已实现现金收益、现金净收益、增量总成本及其为非正数的原因、证据和统计边界；不能用“无限 ROI”或其他除法结果替代绝对金额。

时长与任务量采用非负、同单位、同口径输入：基线与试点时长使用相同时间单位、任务起止点和样本规则，有效任务量使用同一任务定义和计数单位。基线单任务总时长中位数减去试点单任务总时长中位数为负时，不称为负的“可释放产能”，而应按相同时间单位报告为新增产能占用或产能损失，说明原因，且不得与现金收益抵消。

可释放产能是时间容量，不是现金收入。只有组织确实减少支出、依据已有预算避免支出，或形成可归因增量毛利时，相应金额才进入已实现现金收益。避免招聘但没有已批准预算、员工时间重新分配、新增文件或新增对话都应在非现金结果中披露。

### 控制归因、年化和重复计算

每次价值报告必须同时写明统计周期、样本规则、归因假设和低/中/高敏感性区间。敏感性分析只改变已经披露的关键假设，例如有效任务量、人工成本或可归因比例，不能改变硬门和事实记录。

短期试点不得无条件年化。若必须形成预算情景，应单列业务周期、季节性、任务量上限、维护成本和失败率假设，并明确这是预测而非已实现收益。交付加速、质量损失避免额和人工成本不能重复计算；同一结果只能进入一个现金项目，并保留计算路径。

质量和风险默认单独报告。只有已经发生、金额可核验且归因清楚的返工支出、赔付、损失或收益，才按相同凭证规则进入现金账。平均效率或现金净收益不能抵消关键错误、未授权动作和其他硬门失败。

### 用登记阈值作决定

价值报告不在结果出现后另设门槛。决策引用 [第 10 章阈值登记表](/bluebook/part-4/10-pilot-roadmap)：

- **扩大**：全部适用硬门通过，目标指标达到登记阈值，证据支持扩大后的任务和权限范围。
- **优化**：硬门未失败，但输入、入口、质量门或人工步骤存在可验证改进点，修改后重新测试。
- **保持试点**：价值方向尚不明确、样本或业务周期不足，继续限定范围取证。
- **停止**：触发硬门、无法形成可验收结果、增量成本不可接受，或继续取证的价值不足。

### 办公动作例子：要不要继续投入自动生成的周报或经营汇报

决定是否继续，不是看有多少人打开过工作流，而是把同一批任务的五件事分开看。先记录输入版本、人工修改、异常、验收和最终结果，再与试点前登记的基线、阈值和硬门对照。

| 要看的部分 | 用普通办公动作怎么判断 | 能得出的结论 |
|---|---|---|
| 时间 | 把输入准备、执行、等待、复核、返工、沟通和异常处理都计入，比较基线与试点的单任务总时长中位数。 | 说明时间是否变化，以及能释放多少时间容量；不能直接说已经省下现金。 |
| 质量 | 记录一次通过、人工修改、退回、复算结果、专业复核和关键错误，不能只统计最终被采用的报告。 | 说明交付是否仍达到同一标准；阶段通过或平均效率都不能掩盖关键错误。 |
| 风险 | 全量记录未授权访问、外发、写入、错误对象、隐私问题、接管和恢复验证。 | 说明是否触发停止条件；价值统计不能抵消硬门失败。 |
| 现金 ROI（现金投入产出比） | 只把已经实际减少的支出、有预算依据的支出避免或可归因增量毛利计入收益，并扣除订阅、实施、培训、复核、返工、维护、治理和已实现失败损失。 | 说明已实现现金结果能否复算；节省工时、新增文件或新增对话不能直接写成现金收益。 |
| 可释放产能 | 用公式计算任务总时长中位数差额乘以同口径有效任务量，单独报告人员可以转去做什么，不能把它当作收入。 | 说明时间容量是否释放；只有真正减少支出、按批准预算避免支出或形成可归因毛利时，才进入现金收益。 |

例如，周报生成得更快，但人工复核和返工变多：时间未必改善，质量要单独说明，现金 ROI 不能用想象的工资节省补上。又例如，经营汇报被更多人使用，但一次关键口径错误导致业务判断改变：先停止，保护原件，人工接管并完成恢复验证，再更新价值账；不能因为使用量高或报告按时生成就继续投入。若硬门全部通过、登记阈值达到且新增范围有相应证据，才进入“扩大”；只有硬门未失败但流程仍需改进，才是“优化”；样本或周期不足就“保持试点”，触发硬门或无法验收则“停止”。

可参考 [第 9 章公开案例图谱（含 32 个待核验场景线索）](/bluebook/part-3/09-public-case-atlas) 选择一个周报或经营汇报形态做记录练习。图谱只帮助理解场景，不提供你的基线、成本或价值结果；普通记录至少包含输入版本、人工修改、异常、验收和结果。

## 案例与证据

以“月度经营报告”为例。团队先记录人工流程中的数据准备、勾稽、解释、审阅和返工，再用同一任务边界记录试点。若生成报告更快，但财务人员增加了复算和修正时间，总时长可能没有下降；若报告提前交付但没有产生已实现支出减少或可归因毛利，提前量应作为业务结果或可释放产能报告，而不是直接写入现金收益。记录时把输入版本、人工修改、异常、验收和结果绑定到同一任务，才不会把“使用过”误写成“产生价值”。

同样，若试点期间出现一次错误口径并改变经营判断，即使平均时长下降，也要在质量与风险层记录，并按阶段门处理。删除失败样本后再计算一次通过率，或只统计被采用的报告，会使分母失真。

本章公式和默认分类属于社区实践规范，不是会计准则、估值意见或已经验证的行业基准。企业应由财务、业务和数据责任人共同确认凭证、归因与适用口径。

## 企业行动

为一条准备复盘的工作流建立一张场景价值账：

1. 由业务负责人锁定场景、任务资格、分母、基线期和试点期。
2. 由使用者逐任务记录输入准备、执行、等待、复核、返工和异常处理。
3. 由内容复核者使用同一验收标准记录一次通过、修改和关键错误。
4. 由数据/安全责任人全量登记未授权、隐私、权限和接管事件。
5. 由财务或相应责任人核验现金收益、增量成本、凭证和归因假设。
6. 分别计算现金结果与可释放产能，并单列质量、风险和敏感性区间。
7. 对照试点前阈值作出扩大、优化、保持试点或停止决定，记录批准人与后续范围。

停止信号包括：基线与试点口径不同；失败任务从分母消失；人工复核或返工未计时；把节省工时直接乘工资写成现金收益；把同一结果重复计入多个项目；短期结果无条件年化；关键错误被收益数字抵消；计算无法回到任务和凭证。

## 边界与下一步

可复算不等于因果关系已经得到严格实验验证。前后对照可能受熟练度、季节性和任务难度影响；低频复杂任务更适合披露完整案例、专业复核和限制，不能伪装成稳定均值。现金结果还应服从组织财务制度和适用会计要求。

价值度量决定工作流是否值得继续投入，不决定产品官方路线。产品、伙伴和生态建议应单独标注公开事实、已实测组合、可行推断与待验证假设，避免把建议写成承诺。
