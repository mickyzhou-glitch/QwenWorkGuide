# V2.0 版本说明

V2.0 是一次观点型重构：全书从罗列功能和场景，转向解释企业如何把一次 AI 交付沉淀为可验证、可复用、可治理的工作流。

## 结构与发布门

- 正文由 17 章收敛为 13 章，另设序章和结语，采用“完成交付、沉淀工作流、进入专业场景、扩展组织能力”的阅读主线。
- 关键主张进入结构化证据台账，公开案例进入结构化案例来源映射；证据状态、来源定位和案例发布门共同决定内容能否进入公开版本。

## 兼容与 PDF

- 旧 URL 继续通过原路径或兼容入口保留，避免既有引用随章节重构失效。
- V1.2 PDF 继续保留在 `/downloads/qwenwork-bluebook-v1.pdf`，V1.3 PDF 继续保留在 `/downloads/qwenwork-bluebook-v1.3.pdf`；两份存档均不在本次重生成。
- [下载 V2.0 PDF](/downloads/qwenwork-bluebook-v2.0.pdf)。该文件统一由 `npm run build:bluebook-pdf` 构建，逐页检查记录见 [V2.0 PDF QA](/bluebook/releases/v2.0-pdf-qa)。

## 发布状态与后续验证

- V2.0 已同步至 GitHub `main`，并通过 GitHub Pages 与 Cloudflare Pages 发布；本次未创建 GitHub Release。
- 真实读者测试和发布后 30 天传播复盘属于发布后验证，应在真实传播周期中另行执行和记录。
