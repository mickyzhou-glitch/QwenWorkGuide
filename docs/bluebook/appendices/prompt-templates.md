# 常用指令模板

## 使用前的 5 个变量

先把下面 5 项填进任何模板：**读者与决策**、**输入范围与截止日**、**输出格式**、**验收规则**、**是否允许执行外部动作**。若其中一项未知，先要求 AI 生成待确认清单。不要把“请专业一点”当成验收标准；改成“先给结论摘要、关键证据、待决事项和下一步”。

```text
角色与读者：
要支持的决定：
输入资料、时间范围与可信来源：
交付物格式、篇幅与截止时间：
验收规则、禁止项与人工确认点：
```

## 文件整理

```text
扫描指定目录，先给出分类方案和预计移动清单，不要直接移动。
按项目、年份、类型和版本分类，识别重复、临时和疑似敏感文件。
确认后执行；不得删除，所有移动生成日志并提供恢复路径。
```

**验收补充：** 输出移动前清单（原路径、目标路径、原因、冲突处理）；同名文件不覆盖；对疑似合同、身份证明、财务或客户资料只标记，不自行外发。完成后抽查 10 个文件能否按日志恢复。

## Excel 分析

```text
读取后先输出字段字典、缺失值和异常值概览。所有汇总与原始明细勾稽，
不得覆盖原文件。生成原始副本、清洗说明、分析表、图表和校验表。
结论区分数据事实、原因推断和待验证问题。
```

**建议增加的校验语句：** “请在结论前列出总行数、去重规则、缺失值处理、关键字段唯一性和汇总勾稽结果。若任一检查失败，停止生成结论并说明原因。”

### 数据分析通用模板

```text
任务目标是为【读者】判断【业务问题】。数据来自【文件/系统】，截至【日期】；
使用【实际/预算/同比】口径，金额单位为【】。先输出字段字典、样本量、缺失值、
重复值和异常规则，等待确认。

确认后生成：1）保留原始数据的副本；2）清洗与口径说明；3）可编辑明细和汇总；
4）关键数字勾稽表；5）结论、可能原因与待验证问题。事实、推断、建议分开写。
任何金额、日期或主键无法核对时标红，不要补造数据，也不要覆盖原文件。
```

## PPT 生成

```text
受众是【角色】，目标是促成【决定】。先给不超过 10 页的故事线，
每页只表达一个观点。图表注明单位、时间和来源；确认后生成可编辑 PPTX。
```

**故事线检查表：** 第 1 页说明决策；每页只回答一个问题；图表有单位、时间和来源；末页有需要确认的行动；演讲者离开原始资料也能理解每个数字。

## 会议纪要

```text
整理为背景、决定、未决问题、行动项、风险与依赖。人名、金额、日期不确定时
列入待确认清单。行动项必须有负责人、截止时间、交付物和验收标准；先生成草稿。
```

### 会议到行动项模板

```text
基于会议转写、参会名单和会前材料，先输出“已确认事实、可能误识别、缺失上下文”。
只有在材料明确支持时才写为已作决定；不确定的人名、金额、日期全部进入待确认。

行动项格式：事项｜负责人｜截止时间｜交付物｜验收标准｜依赖｜证据位置。
不要自动创建待办、发送邮件或更新项目系统；先给出待写入清单和预览，等负责人确认。
```

## 行业研究与定时任务

```text
先给问题树和来源计划，优先官方、监管、公司披露和原始研究。
每个关键主张保留来源、日期、口径和冲突说明；事实、判断和建议分别标识。
若设为定时任务，限定来源范围、去重并设置失败时的明确说明，禁止自动对外发布。
```

### 研究证据链模板

```text
研究问题是【】；读者需在【日期】前决定【】。先给问题树、假设和来源计划。
每条资料生成证据卡：主张、原始链接、机构、发布日期、访问日期、原文位置、
统计口径、可信级别、局限与冲突。优先监管、统计、公司披露和原始访谈。

报告分为“已核验事实、基于证据的推断、建议、待确认问题”。没有来源、日期或
口径的数字不能进入结论。请列出 5 个最可能推翻当前结论的问题。
```

## 任务交付与审核模板

```text
你将为【读者】完成【任务】，支持其决定【】。仅使用【资料】，时间范围【】。
先复述任务、列出输入缺口和执行计划；我确认后再继续。

最终交付为【格式】；必须包含【章节/表格/附件】。通过标准：
【数字可勾稽、来源可追溯、格式可编辑、结论可执行】。
禁止【外发、写入系统、删除、使用未授权资料】。涉及任何外部动作时，先给变更
清单、影响范围与回退方案，等待明确确认。
```

## 调试提示词的顺序

输出不理想时，先检查输入是否缺失、口径是否冲突、产物定义是否模糊，再调整措辞。每次只改一个变量并保留样本：任务卡、输入版本、输出、人工修改和验收结果。这样才能知道哪条规则真正有效，而不是不断累加更长的提示词。
