# 常用指令模板

## 什么时候使用这份资料

如果你只是第一次整理自己的文件、数据、周报或会议纪要，先选一个具体任务并完成一份可编辑、可核验的草稿即可。只有当你想把任务做得更稳定、交给同事复用，或需要按统一格式调用时，再使用本附录的模板。它是深入资料，不重新定义第 10–12 章的阶段门、动作权限、工作流运营或失败接管规则。

本附录只提供调用方式，不定义新的规范。开始前，先按 [第 2 章任务交付协议](/bluebook/part-1/02-task-delivery-protocol) 填写唯一任务卡；研究主张按 [第 8 章研究与证据链](/bluebook/part-3/08-research-evidence-chain) 建立唯一证据卡；发送、写入、删除、发布等动作按 [第 11 章安全治理](/bluebook/part-4/11-security-governance) 执行相应控制。

下列模板中的 `【】` 和空白线由读者填写。模板里的安全、确认和验收语句用于调用上述规范，不能取代权威章节。

## 文件

```text
请依据【已按第 2 章填写的任务卡】处理【文件或目录】。

先只读取并输出：文件清单、版本与日期、重复或冲突项、缺失输入、疑似敏感内容，
以及拟执行步骤。未经任务卡授权的资料不要使用，不确定的文件只列入确认清单。

交付【目录清单/分类建议/差异报告/可编辑文件】，并按任务卡的验收要求自检。
如需移动、重命名、写入或删除，先按第 11 章核对所需控制，展示对象、影响、
确认点与回退方式；取得相应确认后再执行，并返回操作记录和恢复验证结果。
```

## 数据

```text
请依据【已按第 2 章填写的任务卡】分析【数据文件或已授权数据源】。

先输出字段字典、数据期间与版本、记录数、缺失值、重复值、异常值和口径冲突，
等待我确认后再生成结论。保留原始输入，不覆盖原文件；任何无法核对的金额、
日期、主键或汇总关系都要明确标出，不得补造数据。

交付【可编辑明细/汇总/图表/校验表】，把数据事实、原因推断和建议分开，
并逐项执行任务卡中的验收。若要写回系统或修改业务对象，按第 11 章执行控制、
确认和回退要求。
```

## 汇报

```text
请依据【已按第 2 章填写的任务卡】制作【汇报主题】的【文档/PPT/讲稿】草稿。

受众为【】，需要支持的决定为【】。先给故事线和每页/每节要回答的问题；
我确认后再生成可编辑草稿。所有事实和数字标明来源、日期、单位与适用口径，
不确定内容进入确认清单，不写成既定结论。

完成后按任务卡验收并列出未解决问题。发送或发布前，按第 11 章展示接收对象、
最终版本、关键内容、影响和回退方式，取得所需确认后再执行。
```

## 会议

```text
请依据【已按第 2 章填写的任务卡】整理【会议材料、转写和参会名单】。

先区分已确认事实、可能误识别和缺失上下文。只有材料明确支持时才写为已作决定；
无法确认的人名、金额、日期和责任归属进入确认清单。

交付【纪要草稿/决定记录/行动项草稿/风险清单】，逐项按任务卡验收。
不要自动发送纪要、创建待办或更新项目系统；如需执行这些动作，按第 11 章
展示拟操作对象和内容、确认点及回退方式，取得相应确认后再执行。
```

## 研究证据链模板

```text
请依据【已按第 2 章填写的任务卡】研究【问题】。

先给出问题树、需要验证的假设和来源计划，优先使用【允许的来源范围】。
对每个最小主张，严格调用第 8 章唯一证据卡规范建卡，不另设字段体系；
逐条核对原文、数字、日期、限定条件和证据冲突。

交付【研究底稿/报告草稿】，明确区分已核验事实、基于证据的推断、建议和
未解决问题。没有足够证据的内容降低结论强度或移出结论。若要发送、写入或发布，
按第 11 章执行相应控制，并保留确认与发布记录。
```

## 任务交付与审核模板

```text
请先审核【已按第 2 章填写的任务卡】是否完整符合第 2 章唯一规范，
不要转换为另一套字段。列出缺失、冲突、无权限输入和无法执行的验收要求；
问题未解决前不要开始生成。

任务卡确认后，仅使用【已授权输入】生成【草稿交付物】。交付前逐项对照任务卡
验收，列出证据位置、人工修改、异常、未通过项和需要最终确认的内容。

如任务包含发送、写入、删除、发布或其他外部动作，只调用第 11 章的动作、数据
和专业后果控制；先展示具体对象、范围、影响、批准记录要求与回退方式，
取得相应确认后再执行。
```
