# 上线硬门执行清单

## 什么时候使用这份资料

如果你只是整理自己的周报或会议纪要草稿，不需要先填写这份清单。准备团队试用、跨系统写入、对外发送、多人复用，或要作上线决定时，再把它作为深入资料逐项检查。它只帮助执行和留存上线证据，不重新定义第 10–12 章的阶段门、动作权限、工作流字段、变更门或失败接管规则；规则仍以对应章节为准。

这份清单用于执行上线判断，不另建阶段门或治理规范。样本数量与三阶段门统一按 [第 10 章试点路线](/bluebook/part-4/10-pilot-roadmap) 执行；动作、数据敏感度、专业后果和 G0–G3 控制等级统一按 [第 11 章安全治理](/bluebook/part-4/11-security-governance) 执行；团队工作流卡统一使用 [第 12 章工作流运营](/bluebook/part-4/12-workflow-operations) 的定义，本清单不复制其字段。

**关键错误、法律、安全和未授权动作是不可放宽的硬门；效率、采用率和满意度是可调整的实验阈值。** 任一适用硬门失败时，不得以平均指标抵消，也不得继续升级。

每个复选项都应关联可打开的证据或批准记录，并写明责任人。无法提供证据时，不勾选。

## 质量与证据

- [ ] 每项验收要求都有检查人、检查方法、退回条件与证据位置，产物能够打开、编辑、复算或追溯。证据/记录：\_\_\_\_\_\_；责任人：\_\_\_\_\_\_。
- [ ] 事实、关键数字、来源、日期和适用口径已经核对；研究主张需要建卡时，已关联第 8 章证据卡。证据/记录：\_\_\_\_\_\_；责任人：\_\_\_\_\_\_。
- [ ] 第 10 章规定的关键错误与场景补充错误均已登记；所有失败、中止和排除任务保留结果与原因。证据/记录：\_\_\_\_\_\_；责任人：\_\_\_\_\_\_。
- [ ] 法律、安全、权限和所需专业复核均有明确结论；任何硬门失败没有被效率、质量或满意度平均值掩盖。证据/记录：\_\_\_\_\_\_；批准人：\_\_\_\_\_\_。

## 动作控制

- [ ] 每个动作均已按第 11 章单独核对 G0–G3 控制等级、数据敏感度和专业后果，没有用整条流程的平均等级代替逐动作判断。证据/记录：\_\_\_\_\_\_；责任人：\_\_\_\_\_\_。
- [ ] 发送、写入、删除、发布、付款和主数据修改的具体对象、范围、影响、确认与回退要求均已按第 11 章落实。证据/记录：\_\_\_\_\_\_；批准人：\_\_\_\_\_\_。
- [ ] 需要事前确认的动作会展示当前批次或本次动作的实际对象与内容，并把批准记录绑定到待执行版本。证据/记录：\_\_\_\_\_\_；批准人：\_\_\_\_\_\_。
- [ ] 涉及持续授权时，已核对其批准范围、工作流版本、执行身份、环境、有效状态与停用能力；边界变化不会沿用旧授权。证据/记录：\_\_\_\_\_\_；批准人：\_\_\_\_\_\_。
- [ ] 需要职责分离的动作已核对执行者与动作批准人安排。证据/记录：\_\_\_\_\_\_；责任人：\_\_\_\_\_\_。

## 接管与恢复

- [ ] 停用开关、人工替代流程、原件保护、受影响对象定位、恢复步骤与恢复后验证均可实际执行。证据/记录：\_\_\_\_\_\_；责任人：\_\_\_\_\_\_。
- [ ] 已用当前版本和真实执行身份实际演练停止、人工接管与恢复，并保存执行和验证记录。证据/记录：\_\_\_\_\_\_；责任人：\_\_\_\_\_\_。
- [ ] 出现未授权外发、删除、付款、主数据修改、重大隐私问题或关键业务错误时，立即停止、人工接管和事件复盘；不得以平均效率提升抵消硬门失败。证据/记录：\_\_\_\_\_\_；责任人：\_\_\_\_\_\_。
- [ ] 事件发生后能够保护原件、阻止继续影响、定位对象、记录批准与实际执行差异，并由指定责任人组织复盘。证据/记录：\_\_\_\_\_\_；责任人：\_\_\_\_\_\_。

- [ ] 空数据或缺少必填输入时会停止生成结论或动作，明确列出缺失项并转人工确认。证据/记录：\_\_\_\_\_\_；责任人：\_\_\_\_\_\_。
- [ ] 字段、口径或版本发生变化时会停止沿用旧证据，转人工接管并按第 12 章执行变更与重验。证据/记录：\_\_\_\_\_\_；责任人：\_\_\_\_\_\_。
- [ ] 重复记录会被识别并隔离，不会静默进入汇总、写入或发送；处理结果经过确认。证据/记录：\_\_\_\_\_\_；责任人：\_\_\_\_\_\_。
